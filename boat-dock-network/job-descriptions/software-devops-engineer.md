# Software / DevOps Engineer (DockOS)

**Reports to:** CEO (later CTO) · **Type:** Full-time or contract-to-hire · **Location:** Remote/NW Arkansas

## Summary
Build and run **DockOS**, the open-source-first platform that operates the company:
GIS/OSP, serviceability + signup, billing, provisioning, NOC, outage, boat dispatch,
procurement, and the Arkansas compliance advisor. You keep OpEx low by building the
right things and buying only what's cheaper than building.

## Responsibilities
- Stand up PostGIS + the DockOS schema; build FastAPI modules and a React/MapLibre
  frontend + offline field PWA.
- Integrate Stripe billing, RADIUS/AAA provisioning, and monitoring
  (LibreNMS/Prometheus/Grafana + vendor controllers).
- Implement serviceability + medium-selection logic, work-order/BOM expansion,
  procurement, and outage-impact workflows.
- Integrate the **Claude API** for the compliance advisor, RFQ/grant drafting, and
  support triage.
- Own DevOps: Docker/IaC, backups, monitoring, security, cheap reliable hosting.

## Requirements
- Python (FastAPI) + PostgreSQL/PostGIS; React; REST/API design.
- Cloud/DevOps (Docker, Linux, CI/CD); pragmatic, cost-conscious architecture.
- Comfort integrating third-party APIs (Stripe, RADIUS, monitoring, LLM).

## Nice to have
- Geospatial (GeoAlchemy2, MapLibre, tiles); ISP OSS/BSS; offline-first PWA; LLM apps.

## Comp
Competitive base + equity option (benchmark to market).
