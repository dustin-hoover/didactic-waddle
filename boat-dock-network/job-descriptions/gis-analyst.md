# GIS Analyst / OSP Records Specialist

**Reports to:** Network Architect · **Type:** Full-time · **Location:** NW Arkansas (hybrid)

## Summary
Own the spatial source of truth. Build and maintain the PostGIS database that drives
every serviceability decision, work order, outage impact, and financial input — from
parcels and LiDAR to as-built OSP records.

## Responsibilities
- Import and maintain parcels/addresses (Benton/Washington/Carroll), USACE shoreline,
  and AR LiDAR (DEM/DSM); keep the reference layers current.
- Compute **premises-passed per zone**, serviceability, and the per-address medium.
- Run **LOS/link-budget** and **viewshed** analyses to rank node sites and validate
  links (incl. over-water clearances).
- Maintain OSP inventory: nodes, links, fiber, drops, poles, CPE, permits; enforce
  as-built completeness.
- Produce the ranked **build backlog** and grant-ready coverage maps.
- Build outage-impact analysis and boat-routing/navigable-water layers.
- Publish web/Felt maps for stakeholders and grant applications.

## Requirements
- PostGIS + QGIS; Python geospatial (geopandas, rasterio, shapely, GDAL).
- LiDAR/DEM analysis; LOS/viewshed; coordinate systems.
- SQL; data-quality discipline; clear cartography.

## Nice to have
- Telecom/OSP records experience; MapLibre/Felt; grant mapping; LiDAR-based RF planning.
