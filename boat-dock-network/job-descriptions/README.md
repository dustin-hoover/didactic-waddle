# Job Descriptions

Ready-to-post JDs for Boat Dock Network. See `docs/08-staffing-plan.md` for the org
design and hiring sequence. Compensation lines are placeholders — benchmark to the NW
Arkansas market before posting. All field roles require comfort working from boats and
a commitment to lake safety and drinking-water protection (Beaver Lake is NW Arkansas's
water source).
