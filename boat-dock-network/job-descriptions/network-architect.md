# Network Architect / RF & OSP Engineer

**Reports to:** CEO · **Type:** Full-time · **Location:** Beaver Lake area, NW Arkansas

## Summary
Own the technical design of a hybrid fiber + fixed-wireless network around Beaver Lake:
the redundant ring spine (including licensed-microwave over-water crossings), zoned
dock/aggregation nodes, and per-address fiber/wireless service decisions. You turn
geography into a buildable, reliable, adaptable network.

## Responsibilities
- Design the core (BGP/ASN, multi-homing to two diverse transit on-ramps) and the ring
  transport spine (licensed microwave + fiber), engineered for redundancy.
- Engineer over-water RF links: path/link budgets, Fresnel + earth-curvature clearance,
  **space diversity** for multipath, seasonal lake-level tolerances.
- Design the access layer: nLOS (Tarana/CBRS), PtMP (Cambium/Ubiquiti), and XGS-PON
  FTTH; define the per-address medium-selection rules.
- Set node build standards (technology-agnostic, swappable electronics) per tier.
- Select and qualify vendors; own interop and spares strategy.
- Partner with GIS on LOS/viewshed analysis; validate every link before build.
- Define capacity/oversubscription and growth-upgrade paths.

## Requirements
- Strong RF/microwave design (licensed + unlicensed), including over-water links.
- IP/MPLS/BGP, PON (GPON/XGS-PON), carrier-grade network design.
- Fluency with link-budget tools and GIS-driven planning.
- Field-practical: understands what's buildable and serviceable by boat.

## Nice to have
- WISP + FTTH hybrid experience; Tarana/Cambium/Ubiquiti/licensed-µW vendor certs;
  rural/grant-funded build experience.

## Comp
Competitive base + equity/profit-share option (benchmark to market).
