# NOC / Support Technician

**Reports to:** Network Architect / Ops · **Type:** Full-time (shift) · **Location:** NW Arkansas (hybrid)

## Summary
Keep the network healthy and customers happy. Monitor the network, triage and resolve
issues remotely, dispatch boat crews when physical work is needed, and provide local,
responsive customer support.

## Responsibilities
- Monitor T0–T3 devices (LibreNMS/Prometheus/Grafana + vendor controllers); respond to
  alerts per runbooks.
- Triage customer issues; resolve remotely (config, provisioning, RADIUS) or dispatch.
- Run the **outage workflow**: identify impact, open tickets, update the status page,
  notify customers, coordinate boat dispatch.
- Provision new customers (activation, rate limits); handle billing/support questions.
- Track KPIs (uptime, MTTR, response time) and improve runbooks.

## Requirements
- Networking fundamentals (IP, DNS, DHCP, PoE, Wi-Fi); NMS/monitoring tools.
- Customer-service skill and clear written communication.
- Calm, organized incident handling.

## Nice to have
- ISP/WISP support experience; RADIUS/AAA; scripting; ticketing systems.

## Comp
Competitive base + shift/on-call differential.
