# Grants & Financing Manager

**Reports to:** CEO/Controller · **Type:** Full-time / contract · **Location:** Remote/NW Arkansas

## Summary
Fund the build with the cheapest capital available. Win non-dilutive grants for
high-cost passings and secure low-interest telecom debt, running the funding pipeline
like a sales pipeline (doc 13).

## Responsibilities
- Track and pursue **BEAD (via Arkansas State Broadband Office), USDA ReConnect/RUS,
  state, and other** programs; own applications end-to-end.
- Build applications from the GIS coverage maps, pro forma, and technical plan; gather
  community-support letters and matching-fund commitments.
- Secure **low-interest debt** (USDA RUS, CoBank, RTFC/CFC, equipment finance).
- Own grant **compliance**: segregated accounting coordination, BABA sourcing,
  environmental reviews, and reporting.
- Maintain the grants pipeline + deadlines; optionally run an automated NOFO scanner.

## Requirements
- Grant writing (broadband/infrastructure preferred) and/or telecom project finance.
- Strong writing, financial modeling, and program-compliance discipline.

## Nice to have
- Prior BEAD/USDA/RDOF awards; RUS/CoBank relationships; rural broadband experience.

## Comp
Competitive; contract + success-based component acceptable.
